# 붉은 글씨로 (재)라고 쓴 그날의 이유

**검측 불합격 판정 대장 — 별지 제50호는 그 부산물이다**

제1회 HIMEC AI 활용 아이디어 공모전 출품작(② 시공·품질관리)의 **웹 목업**입니다.
제안자 : 박용환 (크리에이티브 넥서스)

> ⚠️ **가상 데이터 고지**
> 이 저장소와 배포된 화면에 나오는 프로젝트명·문서번호·장비 태그·인명·수치는 **전부 지어낸 값**입니다.
> 실제 기업·발주청·현장·프로젝트·실적을 한 건도 쓰지 않았습니다.
> 프로젝트는 「예시 데이터센터 A / B / C」, 시공사는 「협력사 갑 / 을」 같은 역할명으로만 나타납니다.
> 표시된 판독률·κ·오결합률은 **화면 설명용 예시값**이며, 실제 값은 제안서가 말한 1단계 첫 4주의 실측으로 정해집니다.

## 1. 무엇을 보여 주는 목업인가

준공을 2주 앞둔 현장 사무실에서, 최종보고서의 마지막 한 칸 「우수시공 및 실패시공 사례」 앞에 담당자가 멈춥니다.
지난 2년간 무엇이 왜 불합격이었는지는 캐비닛의 스캔 수천 장 안에 있고, 결국 기억나는 두세 건이 적힙니다.

이 목업은 그 장면에 대해 다음을 화면으로 보여 줍니다.

- 서명이 들어 있는 **스캔 원본은 손대지 않고 해시로 봉인**한 채 읽기 전용으로 둔다.
- 그 **옆에** 판정의 이유만 다섯 칸으로 옮겨 적는 **대장**을 만든다.
- 대장에서 **별지 제50호 초안**을 뽑는다. 산출물은 대장이고 서식은 그 부산물이다.
- **작성 시점이 준공 직전에서 사건 직후로 옮겨 간다.** 서식·인력·법정 절차는 하나도 바뀌지 않는다.

하지 않는 일도 화면에 적었습니다 — 원문에 남지 않은 원인을 만들지 않고, 원본을 대체·수정하지 않으며,
검색창이나 지식그래프를 만들지 않고, 현장 사진을 입력으로 받지 않으며, 결재를 차단하는 게이트가 아닙니다.

## 3. 아키텍처 — AI 구간과 규칙 구간의 경계

안전장치는 기능이 아니라 **층의 분리**입니다. 오차의 성질이 층마다 다르므로 계측 방법과 합격선을 따로 둡니다.
OCR을 규칙에 묶으면 가장 큰 오차 원천이 감춰지므로 **인식층을 독립시켜 판독률로 잽니다.**

```
  서명이 든 스캔                                              불합격 판정 대장
  (검측요청·결과통보 /   →  인식층  →  판단층(AI)  →  결정층(규칙)  →  사람  →  (다섯 칸)
   시정지시 / 재검측)      확률적       판단           결정론        확정·서명       ↓
        ↓                                                                    별지 제50호 초안
  원본 = 읽기 전용                                                              (부산물)
  해시 봉인 (쓰기 경로 없음)
```

| 층 | 입력 | 하는 일 | 성질 · 계측 | 화면 색 |
|---|---|---|---|---|
| **인식층** | 스캔 PDF·TIFF | 서식 영역 검출, 인쇄 필드와 손글씨 영역 분리, 문자 인식 | **확률적.** 판독 가능 비율로 계측, 임계 미만은 「미확인」 | 갈색 |
| **판단층(AI)** | 인식 결과, 인쇄 서식 필드 | ① 결함 **유형 정규화** ② 원검측·시정지시·재검측 **사슬 추론** ③ 조치사항의 **시정 유형 분류** ④ 전자 이슈 로그 **종결 사유 3분류** | **판단.** 감리원 2인의 일치도(κ)가 상한 기준선 | 보라 |
| **결정층(규칙)** | 판단층 결과 | 서식 번호 판별, “(재)” 표기 검출, 공종·부위·날짜 키 부여, 서식 칸 배치, **원본 해시 봉인·색인**, 권한 분리 | **결정론.** 해시 대조 100%가 합격선 | 청록 |
| **사람** | 대장 초안 | 사건 단위 확인·수정·확정, 사슬 끊기와 사유 기재, 서식 확정·서명 | 법적 판정 행위 | 남색 |

**AI를 쓴 자리는 둘뿐입니다.** “배관 구배 불량”과 “슬로프 부족”과 “역구배”를 한 유형으로 묶는 일,
문서번호가 끊긴 세 장을 한 사건으로 잇는 일. 반대로 **규칙으로 되는 일에는 AI를 붙이지 않았습니다** —
“(재)” 검출, 칸 배치, 해시 대조는 전부 결정층에 있습니다.
그리고 **손글씨가 읽히지 않아도 대장의 뼈대는 섭니다.** 사슬 추론은 인쇄 서식 필드만으로도 돌아갑니다.

## 4. 검증 설계

**정답셋은 두 갈래로 준비합니다.**

1. **있으면 즉시** — 완료 현장이 실제 제출한 「우수시공 및 실패시공 사례」 서식을 그대로 정답셋으로 씁니다.
2. **없으면 이렇게** — 감리원 2인이 독립적으로 손수 작성한 대장으로 대체합니다.

어느 쪽이든 먼저 **두 사람의 판정 일치도(κ)를 재고 그 값을 AI 성능의 상한 기준선**으로 삼습니다.
사람 둘도 갈리는 자리에서 시스템에 그 이상을 요구하지 않습니다.
목표는 “AI가 사람보다 낫다”가 아니라 **“사람의 판정을 표준화한다”**입니다.

**파일럿은 한 항목으로 좁힙니다** — 기계 공종 배관·덕트 계열 불합격 건, 완료 현장 3건, 기간 12주.
대상은 활자 검측조서이며 손글씨분은 실측 후 2단계 범위를 정합니다.

**지표는 층별로 따로 잽니다.**

| 층 | 지표 | 합격선 |
|---|---|---|
| 인식층 | 활자 검측조서 판독 가능 비율 | 기준 미달 시 스캔 경로 중단 |
| 판단층 | 유형 정규화 κ (감리원 2인 κ 대비 도달률) | 2인 κ의 50% 미만이면 규칙 사전으로 환원 |
| 판단층 | 사건 사슬 연결 정확도 | 참고 지표 |
| 판단층 | **사슬 오결합률 (별도 지표)** | 초과 시 사슬 자동 제안 중지 |
| 결정층 | 원본 해시 대조 | **100%** — 한 건이라도 어긋나면 중단 |
| 산출물 | 별지 제50호 칸 단위 일치율 | 1단계 0.6 → 2단계 0.75 |
| 새 지표 | 사건 직후 확정 비율 / 유형별 누적 건수 | 기존 목표가 걸려 있지 않은 새 지표 |

사슬 오결합률을 굳이 떼어 낸 이유는 **잘못 이어붙인 사건은 대장에 조용히 남기 때문**입니다.

**반대 방향 표본을 일부러 섞습니다.**

- 합격 종결 뒤 준공 후 하자로 돌아온 건
- 같은 층 같은 부위에서 며칠 간격으로 벌어진 **별개 사건 쌍**(이어붙이면 안 되는 문서 쌍)
- 구형 양식·타사 양식 묶음

화면 2의 `EV-2026-0455 / EV-2026-0456` 행이 그 표본입니다. 감리원이 마지막 마디를 끊고 사유를 남기며,
그 건이 **오결합률의 분자**가 됩니다.

**중단 조건 셋.**

1. 판독 가능 비율 기준 미달 → 스캔 경로 중단, 2단계 초점을 전자 이슈 로그의 종결 사유 3분류로 먼저 돌린다.
2. 사슬 오결합률 합격선 초과 → 사슬 자동 제안 중지, 사람이 직접 잇는 방식으로 되돌린다.
3. 유형 정규화 κ가 2인 κ의 절반 미만 → AI 정규화를 내리고 규칙 사전으로 환원한다.

## 6. 로컬 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 정적 프리렌더 확인
```

- Next.js 16 (App Router) · TypeScript · Tailwind CSS v4
- 서버·데이터베이스·외부 API 호출이 없습니다. 표시 데이터는 전부 `lib/data.ts` 안의 정적 상수입니다.

```
app/
  page.tsx          화면 0 — 개요 · 흐름 (SVG 흐름도)
  original/         화면 1 — 원본 봉인 뷰
  ledger/           화면 2 — 불합격 판정 대장
  form50/           화면 3 — 별지 제50호 초안
  metrics/          화면 4 — 지표 · 검증 · 로드맵
components/
  Chrome.tsx        머리띠(공모전 표기 · 가상 데이터 배지) · 좌측 화면 목록
  ui.tsx            층 배지 · 카드 · 근거 좌표 칩 등 공통 요소
lib/
  data.ts           표시 데이터 (전부 가상)
```

## 7. 고지

- 이 목업은 아이디어 전달을 위한 **화면 시연**이며 실제 운영 시스템이 아닙니다. OCR·AI 추론은 실행되지 않고,
  화면의 신뢰도·κ·판독률은 미리 넣어 둔 예시값입니다.
- 실제 도입 시에는 서명·성명·직인이 든 문서를 다루므로 **처리 근거를 먼저 확보하고 마스킹을 선행**하며,
  대장에는 직급·역할만 남기고 처리 범위·보관 기간·익명화 키 관리 주체를 착수 문서에 명시합니다.
- 대장은 **사내 개선 목적에 한해** 쓰며 계약·분쟁 자료나 개인 평가 자료로 쓰지 않습니다.
- 인용한 법령·지침·서식 관련 서술은 제안서 본문의 근거 표기를 따릅니다. 이 저장소는 화면 목업만 담습니다.
